# 💰 Personal Finance Tracker

A simple and colorful Personal Finance Tracker made in Python.

## ✨ Features

- Add Income & Expense
- View All Transactions
- Financial Summary
- Expense Pie Chart
- Delete Transactions
- Search Transactions
- Monthly Summary
- Bar Chart Visualization
- Backup System
- Beautiful Colored Interface

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## 🚀 How to Run

1. Clone this repository
2. Install the required packages:
   ```bash
   pip install pandas matplotlib
3. python main.py
